どっかで見たことある3Dゲー｡( 一部Claude )<br>
現在のVer → Ver.1.4.0 (11/10)<br>

アプデ内容<br>
・マップを拡大（76m → 100m四方）<br>
・地下通路を追加（西の坂道から入り、東の部屋のはしごで地上へ出られる）<br>
・はしごを追加（近づいてWで登る / Sで降りる / Spaceで飛び降り）<br>
・高い塔（12m・16m）と展望台（8m）を追加<br>
・マップのデータを map.js に分離（形を変えるときはこのファイルだけ編集）<br>
・公開中の最新バージョンと違うと、更新のお知らせを表示（version.json と比較）<br>
・チャットの文字数上限を50→100文字に変更<br>
・チャットのURLを自動でクリックできるリンクに変更<br>
・チャットに送信日時を表示<br>
・マップに塔・スロープ・階段・柱を追加<br>
・足場の上でもジャンプできるように修正<br>
・チャット・入退室ログの表示を安全化<br>

開発メモ<br>
・バージョンを上げるときは index.html の window.APP_VERSION と version.json を同じ値にする（違うとデプロイが止まります）<br>
・マップの形は map.js を編集（座標の書き方は map.js の先頭コメント参照）<br>
